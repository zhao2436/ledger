在手机上怎么拿账单
  1. 微信：我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单 → 用于个人对账，填邮箱，收到的是 zip，里面有 csv。
  2. 支付宝：我的 → 账单 → 右上角 … → 开具交易流水证明 → 用于个人对账，同样发到邮箱，是 zip。
  3. 把收到的 zip 原样传进来就行，不用解压。
